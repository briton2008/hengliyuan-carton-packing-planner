# Contributing

Open a focused bug report or feature request before a substantial change. Provide synthetic examples, expected behavior and reproduction steps. Never include customer data, personal details or credentials.

Run `npm ci --ignore-scripts`, `npm test`, `npm run check:release`, `npm run build` and `npm run test:browser` before a pull request. Preserve unknown values, units, entered conditions and business limits. Do not add guessed prices, packing rules, product claims, sample rankings or automatic submissions. Report validation failures rather than silently changing customer inputs.

Change only this tool. Explain what changed, why and how it was checked. Contributions to code are under the repository MIT license; brand assets remain subject to TRADEMARKS.md.
