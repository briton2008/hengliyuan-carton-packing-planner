# Hengliyuan Carton Packing Planner v0.1.0

Initial independent release. Plan single-SKU cartons or a mixed single-carton trial from measured packs, with interactive 3D and PDF.

Includes company-template review PDF, browser-only state, no login, no automatic submissions and no private company/customer database. Rectangular-envelope heuristics do not prove global optimality, physical support, carton strength, safe handling, pallet or container suitability.

See README for local use, static deployment and tests. Code MIT; brand identifiers separately reserved. Live demo: https://briton2008.github.io/hengliyuan-carton-packing-planner/
